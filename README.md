# #RaiseThemRight Website

A ready-to-upload Next.js website for **#RaiseThemRight**, a public awareness initiative by Nathlee R. Grant.

## Deploy on Vercel

1. Upload this folder to a new GitHub repository.
2. Go to Vercel and select **Add New Project**.
3. Import the GitHub repository.
4. Click **Deploy**.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
